账号变成了一个完整的入口：设置页最上面就是它，点进去能改头像、改昵称、改密码，还能开两步验证。

- 头像：从相册挑一张，自动裁成方形、压到 320px 再传；竖拍的照片会按 EXIF 转正。不想留了就「去掉头像」，回到写着名字首字的那种圆头像。设置页顶部也会显示同一个头像。
- 昵称：最多 24 个字，改完立刻生效。邮箱只读——它是登录名，改它等于换账号。
- 密码：填一遍当前密码、两遍新密码。这台手机不用重新登录，别的设备下次登录用新的。
- 两步验证：扫码（认证器扫不上也能手动输入密钥）→ 输六位数 → 拿到 8 个一次性恢复码，只显示这一次。开启之后登录要多一步：密码对了先给一张五分钟的票据，验证码过了才发令牌。关掉要输密码，拿到手机的人一把关不掉。
- 设置页顺序也调了：账号在最上面，账号下面才是外观、图标、账本、显示、数据和关于。
- 服务端相应加了改资料、改密码、头像、两步验证（TOTP，自己算的 HMAC-SHA1，没引第三方库）和二次登录校验。
