## 0.17.0

**换底子：本机账本从一份 JSON 文件改成 SQLite（`ledger.db`）**

- 以前每改一个字都要把整份账本序列化、写临时文件、原子替换、再拷一份备份。账目攒到几千条以后，
  那一下写盘是白白烧掉的。现在一次编辑只写动过的那几行：账目按 id 比对新旧两份，
  只 upsert 改过的、只删真没了的；分类、规则这类有序小表顺序变了才整表重写。
- **升级不会丢账**：第一次启动会把老的 `ledger.json` 读进数据库，然后把原文件改名成
  `ledger.imported.json` 留档——不删，迁移出岔子还能从文件里捞回来。
- 数据管理页顶上那条改成「本机数据库」+ 实际占用（连 `-wal` / `-shm` 一起算）。
- 导出没变：还是那份桌面端能直接打开的 `ledger.json`。库归库，交换格式归交换格式。

**服务端也一起换了**（1.3.0，已经上线）

- 用户、版本包、登录与下载事件、每人的账本快照各一张表，`node:sqlite` 直接读写，
  不再整库读进内存再写回去。
- 老 `data/db.json` 在第一次启动时自动导入，原文件改名成 `db.json.migrated-<时间>`。
  这次线上搬的是 2 个账号、1 份 3764 条的账本、10 个版本记录，搬完数字一个不差。
- 管理台的概览改成 SQL 计数，趋势图还是拿回 JS 按时区分桶（容器里不一定有 tzdata）。
