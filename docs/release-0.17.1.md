## 0.17.1

### 退款配对独立成页

以前退款只能在条目详情里关联，而且得这笔「已经退过一点」才看得见那张卡——
一笔从没配过的新消费根本没有入口。现在：

- **设置 → 账本 → 退款配对**：一整页分三堆——待配对的退款、还能退的支出、已经配好的对。
- 三道筛子：搜索（平台、分类、账户、金额都能搜）、时间范围（全部 / 近 90 天 / 近 30 天）、
  「只看金额对得上」。
- 选中一条，底下出现「挑对应的那笔」：弹层里按「金额一致 → 日期最近」排，
  每个候选旁边写着差多少、隔了几天；金额对不上也能放开挑（跨平台退、分期退、手续费吃掉一点都常见）。
- 待配对里「金额正好、日期最近且唯一」的可以一键自动配对，拿不准的留给人挑。
- 已配对那栏每对都能看两条明细、打开原消费、解除关联；转账不算退款，不会混进来。

### 条目详情

「退款关联」卡对所有账目都出现了（转账除外），没配过的支出显示「没有关联退款」，
点一下就能挑退款；候选列表加了「金额不一样也显示」开关。
